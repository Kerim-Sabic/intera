# Beta.11 integrated camera and Mac evidence

This is a follow-up to beta.10, preserving the existing desktop, direct Soniox setup, glossary, local meeting library and billing foundations. Branch: `codex/gaze-companion`; review: https://github.com/Kerim-Sabic/intera/pull/5. The branch name is historical: this implementation does not launch a companion application. No merge, public release, production deployment, purchase or Apple enrollment was performed.

## IMPLEMENTED

- Actual Swift CoreMediaIO source/sink extension and a trusted main-process N-API bridge. Explicit activation, bounded frame submission, stop/quit cleanup, producer signing/team checks, and black output after stale input.
- Internal local worker wrapping the pinned upstream MediaPipe/TensorFlow pipeline; preview, correction toggle and calibration. Virtual output can continue while reading, with a persistent Stop control. No webcam microphone, frame recording, cloud video processing or frame uploads.
- Reviewed-model hash/path checks, physical-camera selection excluding Intera Camera, and a pinned OpenCV backend. Model approval is never generated by the app.
- Mac runtime/extension preparation and Forge bundle integration with separate signing entitlements. These scripts are implemented; a complete signed camera bundle has not been produced.
- Playback acquisition deadline fixes and an explicit documented compatibility option applied after restart. Choosing it does not establish successful playback capture.
- Native close-event timing correction in the Mac reader-reopening test. Earlier failures are retained below; this is not a physical Dock-activation verification.
