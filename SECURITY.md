# Security reports

Intera is an internal beta. If you find a vulnerability, use GitHub's **Security → Report a vulnerability** option when it is available for this repository. If that option is unavailable, open a public issue titled **Security contact request** with no technical details so the maintainer can arrange a private channel.

Do not post an exploit, API key, recording, transcript, patient information, identity document, or payment detail in a public issue. For ordinary reproducible bugs without sensitive content, use the bug report template.

The supported work is the current beta branch and its reviewed successors. Unsigned development packages and old builds are not public releases. Please include the exact Intera version, platform, and a synthetic reproduction when reporting privately.
