Original exploration generated with the OpenAI image-generation tool on 2026-09-29. Three actual generated PNGs are retained in `explorations/`. They are visual concepts, never application screenshots.

1. Bridge: paired figures and arch. Clear metaphor, but dots weaken the small silhouette and suggest a people-directory icon.
2. Paired forms: opposing conversational brackets. Strong silhouette and useful flat geometry. Selected; refine away narrow internal notches to preserve the negative-space passage at 16 px.
3. Ribbons: dynamic connection. Clear at medium size, but rotation resembles a synchronization control more than a reading instrument.

Production SVG geometry is a separate, manually authored refinement inspired by direction 2. It is editable paths, not an embedded generated raster. Wordmark is deliberately typeset as Intera using the operating system's Segoe UI / system sans-serif. No font files are bundled. Generated exploration has no third-party reference image or stock artwork. No trademark clearance is claimed.

Palette: ink #202D3C, ivory #F5F3ED, blue #6D91BB. Use ink/ivory monochrome for small symbols; blue is a secondary accent. Clear space: at least 12 units around the 64-unit symbol. Minimum symbol: 16 px; wordmark lockup: 120 px wide. Never stretch, add medical symbols, or use a gradient in the flat mark. App-icon background may use restrained depth.

Reproduce exports with `npm run brand:export`. The command writes genuine PNG-based multi-resolution ICO and ICNS containers plus SVG masters, transparent PNGs, favicon and a 1200×630 social image. System-font rendering can differ between hosts; masters remain editable. Whop upload dimensions are validated against its actual uploader separately. Generated assets do not establish merchant approval or app readiness.

Generation briefs: each direction requested one original centered geometric symbol in ink/ivory/cool blue, legible at 16 px, with no generated typography, microphone, waveform, sparkle, robot, medical cross, Apple mark, existing-logo reference or product mockup.
